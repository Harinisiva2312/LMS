# LMS
SkillWave – Cloud-Based AI Learning Management System

SkillWave is a Cloud-Based AI Learning Management System developed using the MERN Stack. It provides an interactive online learning environment where students can access courses, track their progress, complete quizzes, earn certificates, and receive AI-powered learning assistance.

🚀 Features
👨‍🎓 Student registration and login
📚 Course browsing and enrollment
🎥 Video-based learning
📊 Learning progress tracking
📝 Quizzes and assessments
🏆 Certificate generation
🤖 AI-powered Learning Assistant
👨‍🏫 Instructor dashboard
🛡️ Admin dashboard
💳 Payment integration
☁️ Cloud-based database
📱 Responsive user interface
🛠️ Tech Stack

Frontend: React.js, Tailwind CSS, Framer Motion
Backend: Node.js, Express.js
Database: MongoDB, MongoDB Atlas
AI: AI API Integration
Payment: Razorpay
Tools: Git, GitHub, Postman, VS Code

👥 User Roles
Student

Enroll in courses, watch lessons, track progress, take quizzes, interact with the AI assistant, and earn certificates.

Instructor

Create and manage courses, view students, monitor progress, and manage certificates.

Admin

Manage users, courses, certificates, payments, and overall platform activities.

🎯 Objective

The goal of SkillWave is to combine traditional LMS functionality with AI-powered learning assistance to create a more interactive, personalized, and accessible learning experience.
